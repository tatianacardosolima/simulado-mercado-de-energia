Questões de MCP: apuração do mercado de curto prazo

Questões sobre a apuração do mercado de curto prazo (MCP) na CCEE: dados de entrada, energia verificada e contratada, balanço energético, recurso e requisito, cálculo NET × PLD, TMMCP, impacto do submercado de registro do contrato, modulação (flat, conforme carga, conforme MRE, declarada) e o relatório Sumário (SUM001).

104 questões comentadas, de múltipla escolha, para estudar para a Certificação de Operadores da CCEE. No simulado, as alternativas são embaralhadas e você pode fazer uma prova cronometrada.

Fazer o simulado CCEE grátis

Questão nº 227Qual é o primeiro curso da trilha de liquidação do mercado de curto prazo da CCEE?

  1. A) Liquidação financeira do MCP
  2. B) Apuração do MCP
  3. C) MRE e risco hidrológico
  4. D) Garantias financeiras
Ver resposta

Resposta: B) Apuração do MCP
A trilha começa pela apuração do MCP; depois vêm MRE, risco hidrológico, exposições, encargos, contabilização, garantias e, por fim, a liquidação financeira.

Questão nº 228Qual é o último curso da trilha de liquidação do mercado de curto prazo?

  1. A) Tratamento das exposições
  2. B) Garantias financeiras
  3. C) Liquidação financeira do MCP
  4. D) Apuração do MCP
Ver resposta

Resposta: C) Liquidação financeira do MCP
A parte financeira começa com garantias financeiras e termina com a liquidação financeira do MCP.

Questão nº 229Quais agentes são impactados pelo processamento do MCP?

  1. A) Somente os consumidores livres
  2. B) Somente as distribuidoras
  3. C) Todos os agentes da CCEE
  4. D) Somente os geradores
Ver resposta

Resposta: C) Todos os agentes da CCEE
Todos os agentes são impactados; o processamento do MCP é o primeiro passo para a liquidação financeira.

Resposta: D) Porque geração e consumo ocorrem simultaneamente, sem armazenamento de energia
No SIN não há armazenamento: tudo o que é gerado é consumido ao mesmo tempo.

O sistema atende as diferenças, geralmente com outra usina gerando acima da previsão.

Resposta: D) Dados de entrada → contabilização → resultados por agente → liquidação financeira
Com medição, contratos e PLD, a CCEE contabiliza, divulga os resultados de cada agente e então ocorre a liquidação financeira.

Questão nº 240O que a energia verificada representa na apuração do MCP?

A energia verificada é a medição mais eventuais alocações do MRE, só para usinas hidrelétricas participantes.

Questão nº 252Para um consumidor, o que é recurso e o que é requisito?

  4. D) Recurso: contratos de venda; requisito: geração

Resposta: B) Recurso: contratos de compra; requisito: consumo
O consumo (medição) é o requisito; os contratos de compra são o recurso (lastro) para atendê-lo.

  4. D) O preço do contrato

O NET, saída do balanço energético, é a entrada da segunda etapa: o cálculo do MCP.

Questão nº 263Em qual caderno das regras de comercialização é feito o cálculo do MCP?

  1. A) Balanço Energético
  2. B) Consolidação de Resultados
  3. C) Medição Contábil
  4. D) Garantias Financeiras
Ver resposta

Resposta: B) Consolidação de Resultados
O cálculo MCP = NET × PLD é feito no caderno Consolidação de Resultados.

Questão nº 264Qual é a fórmula do MCP para cada período de comercialização j e submercado s?

  1. A) MCP = NET + PLD
  2. B) MCP = NET ÷ PLD
  3. C) MCP = NET × PLD
  4. D) MCP = PLD − NET
Ver resposta

Resposta: C) MCP = NET × PLD
O MCP de cada hora e submercado é o NET multiplicado pelo PLD daquela hora e submercado.

Questão nº 265Um consumidor tem NET de +20 MWh numa hora em que o PLD é R$ 220/MWh. Qual o resultado no MCP?

  1. A) Não há resultado
  2. B) Recebe R$ 240
  3. C) Recebe R$ 4.400
  4. D) Paga R$ 4.400
Ver resposta

Resposta: C) Recebe R$ 4.400
20 × 220 = R$ 4.400 a receber, pois ele consumiu menos do que comprou.

Questão nº 266Um gerador tem NET de −20 MWh numa hora em que o PLD é R$ 220/MWh. Qual o resultado no MCP?

  1. A) Não há resultado
  2. B) Paga R$ 200
  3. C) Paga R$ 4.400
  4. D) Recebe R$ 4.400
Ver resposta

Resposta: C) Paga R$ 4.400
−20 × 220 = −R$ 4.400: ele paga, porque vendeu mais do que gerou.

Questão nº 267O cálculo NET × PLD é feito para quais horas?

  1. A) Só para os dias úteis

Questão nº 270O que a fórmula do TMMCP soma?
